# PlexonShops 3.0.0-rc.1

Phase 2 release candidate. Stable promotion is intentionally blocked until PlexonCraft runtime certification.

## Highlights

- discovery-first `/pshops` hub and compact shop review profiles
- cached browse, category search, favorites, featured shops and bounded recent visits
- authoritative availability resolver shared by GUI and teleport paths
- one shared warmup/coordinator task instead of one completion scheduler per teleport
- preserved Vault charge/refund and post-success visit accounting
- versioned additive SQLite schema with pre-migration 2.2.1 backup
- strict candidate configuration validation and transactional reload rollback
- actor/action/shop/revision-bound two-stage destructive confirmation
- expanded cache-only PlaceholderAPI and immutable public discovery API
- administration profiles with feature/status controls and teleport diagnostics

## Compatibility

Published rollback boundary: `v2.2.1` at `81c77e936194de2d46fd40221ea57a1f65c07b34`.
Existing shop UUIDs, owners, names, descriptions, locations, ratings, visitor statistics, labeled items and Vault economy ownership are preserved.

## Runtime certification

Not executed for this prerelease. Do not promote to stable until the Phase 2 PlexonCraft runtime gates pass.
