# PlexonShops 2.2.1

PlexonCore 2.0.4 lifecycle/provenance maintenance release.

## Fixed

- Expands the supported Core API range through Core 2.x.
- Pins build and release verification to the exact PlexonCore 2.0.4 JAR and SHA-256.
- Uses Core 2 owner-aware module state transitions and owner-scoped unregister cleanup.
- Makes stable GitHub release assets immutable by refusing to overwrite an existing tag/release.

## Compatibility

- Paper 26.2
- Java 25
- PlexonCore 2.0.4 certification baseline
- Vault economy remains authoritative for shop teleport fees/refunds.

Shop persistence, APIs/events, ratings, visitor tracking, sub-shops and economy behavior are otherwise unchanged.
